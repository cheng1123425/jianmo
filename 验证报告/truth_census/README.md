# truth_census —— 方案④「锚点驱动」的实验区

**状态**：实验区产物，**未接主干、未提交批准**。不 import 项目任何模块，不碰 `steps/` 与 `lib/`。

## 这是什么

用真值 STEP 造一把「度量尺子」，用来回答**"我建的模型和真值差多少"**——
不参与读图、不碰识别逻辑，所以它本身不存在训练/测试泄漏问题。
但它必须只用测试集来做（否则尺子会被调成"只量得出我想量到的"）。

## v3 重构（2026-10-16）：读图层算子化

**动因**：12 件循环跑 9 轮后复盘，发现反复重写的一直是**同一类代码**，而不是建体——
`segs_of`/`view_of` 抄了 3 份、标注收集抄了 2 份（逐字相同）、`solve_scale` 调用 2 处、
`detect_circles` 改了 4 版、`solve_scale` 改了 5 版、`cluster_views` 改了 4 版。

**关键判断**：**建模算子一个都不缺**。9 轮里用到的建模动作只有 3 个
（`Cylinder−Cylinder` / `extrude` / `revolve`），`z2c_conv/op_lib.py` 全都有；
失败全在「从图元里量出几何量」这一步。
而 Zero-to-CAD 候选榜 top30 **全是建模动词**，一个读图算子都没有
（它是「代码/文本 → CAD」，IR 给定，不需要读图）⇒ **这一族只能自己挖**。

**做法**：新建 `readops.py`（读图算子库），`views_to_3d.py` 三个 route 改为「调度 + 算子」。

| 文件 | 行数 | 变化 |
|---|---|---|
| `views_to_3d.py` | 451 → **279** | −38%，只剩调度 / 建体 / 收尾 |
| `readops.py` | **300**（新增） | 10 个算子 + "为什么这么定"的注释 |

**readops 算子清单（10 个，全纯函数）**

| 类 | 算子 |
|---|---|
| 空间分派 | `by_view` / `segs_in_view` / `extents_of` |
| 几何提取 | `circle_of` / `loop_of` / `axis_view_of` / `pair_of` |
| 数值标定 | `annos_of` / `scale_of` / `snap_to` |

**回归验证（判据是"行为不变"）** —— 先录基线 → 重构 → 重跑：

- `baseline_before_refactor.json` 与 `baseline_after_refactor.json` **逐字节一致**
- 11 件逐件 `diff.volume_pct` 全部相同（含 FAIL 的 sj-011）
- 出三维 **10 件**不变、PASS **1 件**（合金管垫片 +0.000%）不变

**两处"看起来像重复、其实语义不同"的保留**

- `by_view`（first-match：回答"这条线属于哪个视图"）vs `segs_in_view`（全集：回答"这个视图里有什么线"）

## v4 剖面线扫描（2026-10-16）：revolve 路线有效，extrude 实测不适用

**核心思想**：剖面线（`剖面线层`）是设计师画的"**这里剖到了材料**"标记 —— **孔/空腔/外面都没有剖面线**。
所以扫描剖面线比走环更本质：直接给出"材料在哪"。

带 3 个坑，都写进了算子注释：

1. **必须求交点，不能取端点** —— 剖面线是 45° 斜线，某轴向 bin 里只有稀疏端点 ⇒
   `r_in` 被当成 `r_out` ⇒ 轮廓退化、体积 −95.29%（回归过）。
2. **必须分段取极值**（`_step_segments`）—— 剖面线有间距 ⇒ 逐 bin 的边界锯齿
   （实测外缘 76.4/77.4/78.4/79.4）⇒ 体积 −17.5%。按边界跳变切段、段内取极值 ⇒ −1.94%。
3. **吸附后必须去重** —— 相邻段内缘吸附到同一 Ø 后完全重合 ⇒ 零长边 ⇒
   OCCT 报 `BRep_API: command not done`。

**新增算子**：`profile_from_hatch`（回转用一维轮廓）、`section_outer_of_hatch`（拉伸用二维外轮廓）、
`half_profile_of`（补轴端点）、`_step_segments`（公共分段）。readops 现 **12 个公开算子**。

### 效果

| 件 | 路线 | 修复前 | 修复后 |
|---|---|---|---|
| sj-009 底部垫片 | revolve | −94.303% | **−1.944%** |
| sj-011 定心垫片 | revolve | FAIL | **出体 −9.067%** |
| 其余 9 件 | — | — | **逐位不变** |

### extrude 路线：**实测不适用**（负结果，如实记录）

8 件 extrude 全测：**7 件的剖面视图里根本没有剖面线**；
唯一的 sj-001 覆盖率仅 **3%**（局部剖的线，不是截面填充）⇒ 扫描出残缺截面、体积从 +106% 变 **−91.6%**（回归）。

⇒ 加**覆盖率判据 `cov >= 0.5`**（只有剖面线铺满视图才算真剖视图的填充），加上后 11 件逐件一致、无回归。

**副产物发现**：剖面线几乎都落在**另一个视图**上
（sj-002→视图2、sj-003→视图1、sj-006→视图2、sj-007→视图1、sj-008→视图3）——
**那些才是设计师真正剖开画的剖视图**，而"按面积选 prof"的逻辑没选到它们。
下一步要拿它们当剖面源，先得证明"该剖视图的截面 == 要拉伸的截面"。

## v5 减孔（2026-10-16）：在剖面视图里直接检测圆

**先纠正一个预设**：原以为要"跨视图对应"（俯视图的圆 → 主视图的孔）。
**实测不需要** —— 当前选的 prof 视图**本身就是俯视图**（sj-002 189×189、sj-007 187×120、sj-008 88×70），
孔在里面就是圆。⇒ 只需"在 prof 视图里检测圆 → 减掉"。

**新增算子**：`components`（端点连通分组）、`circles_in_view`（多独立圆）、
`pick_holes`（同心组取最内层）、`point_in_polygon`（射线法）。

> `circles_in_view` 与 `circle_of` **不是重复**：前者先分组再检测，能处理**不同心的孔阵列**；
> 后者假设所有圆同心（按到质心距离聚类），只适用于轴剖视图。

**三道过滤**（第三道有真值依据）：

1. 太大（≥0.8×视图边长）⇒ 外轮廓/大凸台
2. 不在轮廓内 ⇒ 不属于该截面

## v6 外轮廓：半边遍历取面（2026-10-16）

**根因**：旧的 `profile.trace_outer_loop` 是"**单起点 + 最左转墙面跟随**"，
只在"沿程无分叉且起点恰在外边界"时正确。实测 8 件 extrude：

| 件 | 分支点 | 旧走环 |
|---|---|---|
| sj-002 | 0 | 12点 / 100% ✓ |
| sj-008 | 0 | **4点 / 面积 0** ✗ |
| sj-003 | **16** | 82点 / **面积 0** ✗ |
| sj-006 | 1 | 56点 / **面积 0** ✗ |
| sj-007 | **8** | 8点 / 100%（真值截面只 64%）✗ |

视图里只要有孔/凸台/台阶线，平面图就出现**分叉**，单路径跟随必然走岔。

**修法**：新增 `profile.faces_of`（标准**半边遍历**）+ `profile.outer_loop`：

1. 每个顶点的出边**按极角排序**
2. 每条半边 `(u,w)` 在 `w` 处取 `u` 的**下一条**（最左转）⇒ 每个面逆时针绕一圈
3. 未被访问的半边各自成面
4. **外轮廓 = 面积最大的面**

`readops.loop_of` 改为**优先 `outer_loop`、失败回退旧算法**。

| 件 | 旧走环 | 半边面 |
|---|---|---|
| sj-003 | +1691.08 | **+362.55** |
| sj-006 | +341.28 | **+162.55** |
| sj-008 | +327.21 | **+162.13** |

## v8 投影原则：视图识别（2026-10-16，用户提示"机械制图还有投影原则你知道吗"）

此前只用投影原则的"配对"，漏了它的完整形态。`projection-rules.md` 三层：

- **§2 轴映射表（基石）**：主视图读(长,高)｜俯视图读(长,宽)｜左视图读(宽,高)
- **§3 三等关系**：长对正(主↔俯,X)｜高平齐(主↔左,Z)｜宽相等(俯↔左,Y)
- **§7 视图选择**：主视图应最能反映形状特征（**"面积最大"已被证伪**）

**可执行推论**：**主视图 ⟺ 同时「与某视图长对正」且「与另一视图高平齐」的那个视图**。
这是**结构性唯一**判据，不依赖尺寸猜测。实测 4 件多视图件（sj-004/005/006/008）全部一次命中，
X/Y/Z 三方向各两路交叉验证通过、与真值 STEP bbox 一致。

| 件 | 主/俯/左 | 旧 `pair_of` 给的 | 投影原则给的 |
|---|---|---|---|
| sj-004 | v2/v1/v0 | prof=77×53, thin=69×53 (axis=y) → 厚度 13 | prof=69×53(主), thin=69×77(俯) → 厚度 14.5 ✓ |
| sj-008 | v1/v3/v2 | prof=88×70, thin=70×70 → 厚度 47.9 | prof=88×70(主), thin=87×58(俯) → 厚度 **40** ✓ |

**效果**：sj-004 **+581.286% → −41.400%**；sj-008 首次走通 extrude+分层（厚 40 ✓、7 层台阶）；
