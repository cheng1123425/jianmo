# 双耳直角支座（ybracket）—— 本机运行说明

> 沙箱无 FreeCAD，`s2_drawing`（TechDraw 出图）只能在你的 Windows 本机跑。
> 沙箱已完成并验证：s0b 读图 → s0_plan → s1 建模（STEP/STL）+ 出图段/闭环段
> （用正交投影替代 s2）。本机跑的是**真 FreeCAD 版**，产出 `.FCStd` 工程图。

## 一、前置检查（跑之前确认）

| 项 | 应满足 | 检查命令 |
|---|---|---|
| Python venv | build123d 0.13.0 + matplotlib | `D:\3d\build123d\.venv\Scripts\python.exe -c "import build123d;print(build123d.__version__)"` |
| FreeCAD 1.1.0 | `freecadcmd.exe` 存在 | 确认 `D:\3d\新建文件夹\FreeCAD 1.1\bin\freecadcmd.exe` |
| A3 模板 | `A3_Landscape_TD.svg` 存在 | `<FreeCAD>\data\Mod\TechDraw\Templates\ISO\A3_Landscape_TD.svg` |

## 二、环境变量（clone 后设一次）

```bat

set MPIPE_FC=D:\3d\新建文件夹\FreeCAD 1.1\bin\freecadcmd.exe
```

## 三、跑全流程（三个图）

```bat
cd <jianmo 仓库根目录>
D:\3d\build123d\.venv\Scripts\python.exe pipe.py --part parts/ybracket --loop
```

产出（在 `parts\ybracket\`）：
- `models\ybracket.step` / `.stl` —— 三维模型（s1_build）
- `ybracket.FCStd` —— FreeCAD 工程图文档（s2_drawing，含关联尺寸对象）
- `drawing.png` / `.pdf` —— 三视图（s3_render）
- `dims_table.png` / `.pdf` / `.md` —— 尺寸对照表（s4_table）

加 `--auto` 可让闭环自动改参数迭代：
```bat
... pipe.py --part parts/ybracket --loop --auto
```

## 六、若本机跑 s2 报错

s2_drawing.py 依赖 FreeCAD，沙箱无法试跑，只做了静态审查 + 适配。若报错：
1. **找不到圆**（`找不到 r=xx`）→ 已改为容错（跳过并告警），不会崩
2. **视图重叠/出框** → 调 `s2_drawing.py` 的 `views` 里 X/Y 与 `PLOT`
3. **FreeCAD 中文输出乱码** → 脚本已 `sys.stdout.reconfigure(encoding="utf-8")`
4. 把报错原文发我，我直接定位
