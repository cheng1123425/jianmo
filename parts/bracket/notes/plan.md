### 0.1 推荐作画/建模顺序

1. ****定基准**：原点放底板中心（X=0, Y=0），底面 z=0；圆头圆心放在 Y=-12。**
   - 理由：底板 + 圆头的定位都从这个原点出发，臂 YZ 侧轮廓的圆心已经在基准里。
2. ****底板**：Rectangle(L, W, align=(CENTER, MIN)) → extrude(T)。**
   - 理由：**底板 Y 用 MIN 对齐**到 [0, 24]，与臂的右端 END_Y=24 端齐平； 改成默认居中会让所有 Y 方向尺寸整体偏移 12。
3. ****两平行臂**：在 `Plane.YZ.offset(±x0)` 上画侧轮廓（圆+切线+三段直线）→ extrude(ARM_T)。**
   - 理由：**斜面最难画的位置放到"侧视面"去画**：臂的 YZ 轮廓是平面图形（圆+直线）， 在 XY 或 XZ 里就变成斜拉伸了；用 YZ 平面画草图，拉伸方向自动沿 X。
4. ****圆头铰接端**（与步骤 3 合并）：CenterArc arc_size = (A_UP - A_DN) - 360 = -183.7°。**
   - 理由：**arc_size 必须是负的**（顺时针走大弧），取正会绕到反向弧 → 轮廓凸向反侧、圆心落到体外、按圆心定位的所有孔切除量为 0。 用 `tangent_point()` 算切点，**不要目测**。
5. ****底板孔**：Locations((±PITCH9/2, W/2)) Circle(D_9/2) → SUBTRACT。**
   - 理由：Y=W/2=12 让孔在底板 +Y 端的中心线上（与臂右端对齐）。
6. ****销孔**：`part - Cylinder(D_PIN/2, ARM_T+12, rotation=(0,90,0))` ×2（轴沿 X）。**
   - 理由：用 `part - tool` 而不用 BuildSketch+SUBTRACT—— 后者在有斜臂时经常切不穿。
7. ****台阶孔**：φ6 沉 + φ3 通两次 SUBTRACT。**
   - 理由：沉孔与通孔是不同深度，必须两次切除合并到一个圆柱。**端面归属待确认**。
8. ****修饰**：无圆角/螺纹，按图原样。**
9. ****出图顺序**：基准 → 主视图（总高+台阶孔）→ 俯视图（底板长宽+2-φ9）→ 左视图（臂水平长+圆头）→ 标注。**
   - 理由：效率要点： - **对称用镜像/两次 Locations，不要复制另一只手工改**； - **打孔一律 `part - Cylinder`**； - **每建一步 print 体积**验证没漏特征； - **切点必须算**，目测的切线在投影里出现折角。

## 2. 构造顺序

1. **底板**　分类=底板
   - 参数：L, W, T
   - 做法：Rectangle(L, W, align=(CENTER, MIN)) → extrude(T)
2. **两平行臂**　分类=臂
   - 参数：ARM_T, ARM_GAP, END_Y, END_Z
   - 做法：Plane.YZ.offset(±x0) 画侧轮廓（圆 + 切线 + 3 段直线）→ extrude(ARM_T)
3. **圆头铰接端**　分类=圆头
   - 参数：R_HEAD, HEAD_Y, HEAD_Z
   - 做法：CenterArc((HEAD_Y,HEAD_Z), R_HEAD, A_DN, (A_UP-A_DN)-360) —— arc_size 必须是负的（顺时针）
4. **底板孔**　分类=底板孔
   - 参数：D_9, PITCH9
   - 做法：Locations((±PITCH9/2, W/2)) Circle(D_9/2) → extrude(T, SUBTRACT)
5. **销孔**　分类=销孔
   - 参数：D_PIN
   - 做法：part - Cylinder(D_PIN/2, ARM_T+12, rotation=(0,90,0))（轴沿 X，贯穿两臂）
6. **台阶孔**　分类=台阶孔
   - 参数：D_CB, D_CS, CS_DEPTH
   - 做法：part - Cylinder(...) ×2（φ6 浅沉 + φ3 深通，轴沿 Y）

## 6. 已知易错点（方案源）

- **CenterArc 的 arc_size 符号**：走 (A_UP - A_DN) 是 +176.3°，会绕到反向弧 → 轮廓凸向反侧、圆心落到体外，所有按圆心定位的孔切除量变 0。必须写 (A_UP - A_DN) - 360 = -183.7°（顺时针走大弧）
- **Rectangle 默认不是居中**：align=(CENTER, MIN) 让底板 Y ∈ [0, 24]，与臂的 END_Y 端齐平；当成居中会让孔位和臂错位 12
- 相切点用 tangent_point() 算，不要目测：目测的切线会在投影里出现折角
- 打孔一律用 `part - Cylinder(...)`：BuildSketch + SUBTRACT 在有斜臂时经常切不穿
- 台阶孔的端面归属原图未标注，改这一段前先看 notes/errors.md 里有没有踩过
