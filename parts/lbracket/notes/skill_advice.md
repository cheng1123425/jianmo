## 5. 高效作画 / 建模步骤

按"基准先行 → 主体 → 次要 → 切除 → 修饰"：

1. **定基准**：原点放在底板底面中心（X=0, Y=0, Z=0）。
   理由：底板、立板、孔的位置都从这个原点出发；所有尺寸无需换算。
2. **底板（带 R9 圆角）**：Plane.XY 上画轮廓——
   `RadiusArc((cx, -W/2), (cx, W/2), R9)` + 三条直线封口 → extrude(BASE_T)。
   理由：★**R9 圆角在轮廓线里直接画，不要先 Rectangle 再 fillet**——
   后者会把底板四条边全倒圆（错了 R9 应该是端弧）。
3. **立板**：Plane.XY * Pos(0, 0, BASE_T) 上 `Rectangle(WALL_T, WALL_L)` 居中放置
   → extrude(WALL_H)。
   理由：居中放置让立板 Y 范围 = [-WALL_L/2, WALL_L/2]，两 φ8 孔的 Y 坐标 = ±WALL_L/2 = ±13
   看似与"Y=0/26"不符——这里改用**绝对坐标**：把立板中心放在 (WALL_X0 + WALL_T/2, 0)，
   Y 范围 [0, WALL_L]，孔 Y=0 和 Y=26。
4. **三角筋**：Plane.XZ.offset(WALL_X0) 画直角三角形——(0, BASE_T) → (0, BASE_T+WALL_H)
   → (WALL_T, BASE_T) → 闭合 → make_face → extrude(WALL_L, 沿 Y)。
   理由：**XZ 平面的 Y 是实物 Z**——三角形顶点必须用 BASE_T 和 BASE_T+WALL_H，不要写 0/WALL_H，
   否则三角筋跑到 Z=0~WALL_H 区间外（低于底板顶）。
5. **底板 φ8 孔**：`part - Cylinder(D/2, BASE_T+1)` 轴沿 Z。
   理由：用 part-tool 而非 BuildSketch+SUBTRACT——BuildSketch 在异形体上易切不穿。
6. **立板顶 2×φ8 孔**：`part - Cylinder(D/2, WALL_L+8)` ×2，轴沿 Y（rotation=(0,90,0)）。
   理由：长度 WALL_L+8 让孔两端各超出 4 mm，确保贯穿。
7. **后续补做**：立板顶 R7 圆角（Fillet edges）、中央矩形窗口（Box 切除）、中央 R6.5 内凹（Sphere 切除）。

效率要点：
- 立板和三角筋**都按 WALL_X0 对齐到 X 方向**，避免一处改两处漏改
- 孔一律 `part - tool`，不要 BuildSketch+SUBTRACT
- 每步 print(part.volume) 验证没漏特征
