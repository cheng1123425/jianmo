> **版本**：v2.0 ｜ **日期**：2026-10-14
> **梳理范围**：`/workspace/jianmo` 项目全部落地代码 + 架构设计文档
> **验证基准**：`guard.py` 13/13 隔离通过、12 个文件语法 OK、闭环端到端冒烟通过

## 1. 系统定位

**一句话**：图纸或文字描述进 → 符合国标的工程图 + PDF 出；所有尺寸只有一个数据源（`params.py`），改一处、三维/STEP/工程图/PDF/尺寸表全部联动重算；出图后自动对照原图闭环自校，错了能定位到"是三维画错、二维标错、还是图本身画错"。

| 能力 | 状态 | 说明 |
|---|---|---|
| 参数化建模 | ✅ 已跑通 | build123d 代码生成式，STEP/STL 导出 |
| 国标工程图 + PDF | ✅ 已跑通 | FreeCAD TechDraw 无界面出图 + matplotlib 落 PDF，300dpi A3 横向 |
| 参数 ↔ 标注联动 | ✅ 已实测 | 改 `dia` 一处 → 标注 `4×Φ8` 自动变 `4×Φ10` |
| 图纸语义解析（输入层） | ✅ 已落地 | `tools/dwg_parser` 三层分离提取，法兰图实测 6 圆全对、12 标注 11 接地 |
| 图纸检验（尺寸链/投影原则） | ✅ 已落地并隔离 | s5b / s6b 两个独立步骤走 mpipe/1 协议 |
| 闭环自校 + 自动修正 | ✅ 已跑通 | 三路校验责任分级，`--auto` 最多 6 轮自动改回 |

**核心差异化**：3D↔2D 尺寸对应关系。工程图上的每个尺寸都是 FreeCAD 关联对象（`References2D` 引用投影边），改三维 → `recompute` → 尺寸值自动跟随——不是"重新贴一张文字"，是活的标注。

## 2. 五层架构

```
┌─────────────────────────────────────────────────────────────┐
│ L0 输入层   drawing.png/PDF ──► s0b_dwgread ──► dwg_semantics.json │
│             （tools/dwg_parser：几何层 / 标注层 / 接地层分离提取）      │
├─────────────────────────────────────────────────────────────┤
│ L1 操作层   s0_plan → s1_build → s2_drawing → s3_render → s4_table │
│             （params.py 唯一数据源，全链重算，STEP 不复用）              │
├─────────────────────────────────────────────────────────────┤
│ L2 闭环层   s5_collect → s5b_dimchain → s6_compare → s6b_projection │
│             → s7_decide → s8_apply → s9_record                      │
│             （三路校验：图纸自洽 / 投影规范 / 模型精度）                  │
├─────────────────────────────────────────────────────────────┤
│ L3 数据源层 params.py（几何）· dims_spec.py（标注规范）· ref_spec.py（原图真值）│
├─────────────────────────────────────────────────────────────┤
│ L4 记录层   notes/：plan_src（人写方案）· plan/model_notes（机器写）·    │
│             errors.md 错误库 · skill_feedback 技能回路                   │
└─────────────────────────────────────────────────────────────┘
```

**贯穿所有层的纪律**：每一步都是独立进程，只通过 `_msg/<stage>.in/out.json` 消息文件通信（协议 `mpipe/1`），`guard.py` 静态扫描强制。

## 3. 十三步流水线全表

### 3.1 步骤总览

| # | 步骤 | 职责 | 读什么 | 写什么 | 零件无关 |
|---|---|---|---|---|---|
| 1 | `s0b_dwgread` | **输入层**：读原图 → 三层语义 | `drawing.png`（可选） | `notes/dwg_semantics.json` | ✅ 回落 |
| 2 | `s0_plan` | 每轮前读图：图纸基准 + 关系表 + 历史错误 → 本轮方案 | params/dims_spec/ref_spec/plan_src/errors/dwg_semantics | `notes/plan.md` | ✅ 回落 |
| 3 | `s1_build` | 三维建模 | params.py | `models/*.step/.stl` | ✗ 零件自带 |
| 4 | `s2_drawing` | STEP → 工程图 FCStd + 投影特征（FreeCAD） | params + s1 的 STEP | `*.FCStd` + `_drawing.json` | ✗ 零件自带 |
| 5 | `s3_render` | 投影特征 → A3 矢量图纸 PDF/PNG | s2 的 drawing_json | `drawing.pdf/.png` | ✗ 零件自带 |
| 6 | `s4_table` | 参数 + 投影 → 尺寸对照表 | params/dims_spec/drawing_json | `dims_table.pdf/.md` | ✗ 零件自带 |
| 7 | `s5_collect` | 投影 → 几何摘要（只提取不判断） | s2 的 drawing_json | out.data 摘要 | ✗ 零件自带 |
| 8 | `s5b_dimchain` | **尺寸链校验**：Σ各段 = 封闭环？漏标/重标/接地可疑？ | dwg_semantics + drawing_json + params | out.data `dimchain` 命名空间 | ✅ 回落 |
| 9 | `s6_compare` | 几何摘要 vs 原图基准 → 差异清单 | ref_spec + s5 摘要 | out.data `issues` | ✗ 零件自带 |
| 10 | `s6b_projection` | **投影原则校验**：长对正/高平齐/宽相等/视图齐全/图尺相符/高度链 | drawing_json | out.data `projection` 命名空间 | ✅ 回落 |
| 11 | `s7_decide` | 三路校验 → 判定 + 修正建议（只决策不动文件） | params + 三路 out.data | out.data verdict/fixes | ✗ 零件自带 |
| 12 | `s8_apply` | 修正建议 → 写回 params.py（**唯一**被允许改参数的步骤） | params + s7 结论 | params.py | ✗ 零件自带 |
| 13 | `s9_record` | 每轮记录：思路/差异/修正/错误条目 | params/dims_spec/plan/skill_feedback | notes/ 三件套 | ✅ 回落 |

### 3.2 执行分组

| 分组 | 成员 | 触发时机 |
|---|---|---|
| CHAIN（正向链） | s0b → s0 → s1 → s2 → s3 → s4 | 每次全链跑一次 |
| LOOP（闭环体） | s5_collect → s5b → s6_compare → s6b → s7_decide | `--loop` 时每轮重复 |
| LOOP_TAIL（轮尾） | s9_record | 每轮结束记一次账 |
| QUICK_CHAIN（中间轮） | s1_build → s2_drawing | 闭环中间轮只重建几何，出图/制表延迟到最后 |
| DEFERRED（延迟产物） | s3_render → s4_table | 中间轮跳过，末轮补跑 |

### 3.3 回落机制（SHARED_STEPS）

零件目录 `steps/` 里**没有**的步骤，若属于 5 个零件无关步骤（`s0_plan`、`s9_record`、`s0b_dwgread`、`s5b_dimchain`、`s6b_projection`）→ 回落根目录通用实现；其余步骤（s1~s8）缺了**启动即报错**并提示怎么补（2026-10-08 起不再静默拿垫片那份顶上）。无图纸的零件跑 s0b 会自动产出空语义，不报错。

## 4. 三条主线怎么跑

### 4.1 主线 A：正向生成（图纸/参数 → PDF）

```
params.py ─► s1_build ─► STEP ─► s2_drawing ─► FCStd + _drawing.json
                                              ├─► s3_render ─► drawing.pdf/png
                                              └─► s4_table  ─► dims_table.pdf/md
```

- STEP 是 **AP214 纯几何**（无参数、无特征树），是"照片"不是"活体" → 每次重新生成，不复用
- 尺寸全部关联到视图边（`References2D`，0-based 可见边下标）；孔心距特例：两圆边 DistanceX 得最近距离（φ75 孔得 325 不是 400）→ 改为从实体读圆柱面轴线
- 尺寸表并置"参数值 vs FreeCAD 实测值"两列，一致打 OK、不一致亮红——把"图纸对不对"从人工核对变成自动断言

### 4.2 主线 B：闭环自校（最多 6 轮）

```
s5_collect（提取）─┬─► s5b_dimchain ──┐
                  ├─► s6_compare ────┼─► s7_decide ─► 判定 ─► s8_apply（改 params）
                  └─► s6b_projection ┘                    │
                                                          └─► s9_record（记账）
```

### 4.3 主线 C：隔离协议（mpipe/1）

| 机制 | 实现 | 作用 |
|---|---|---|
| 消息文件 | 每步只读自己的 `.in.json`、只写自己的 `.out.json` | 步骤间零直接耦合 |
| 权限声明 | `in.refs` 列出本步**被允许读**的全部文件，读前校验 sha256 | 读越界即抛 RuntimeError |
| 静态扫描 | `guard.py` 禁跨步骤 import、禁硬编码路径读别人产物 | 违例拒绝运行（当前 13/13 通过） |
| 写权限管制 | 运行时只有 `s8_apply` 能改 params.py | 校核步骤不能越界改建模输入 |
| 命名空间隔离 | s5b/s6b 的产出收在 `dimchain`/`projection` 键下 | `in_data_from` 平铺合并时同名键不互踩（曾因此出过致命 bug，见 §7） |

## 5. 两个图纸检验隔离步骤（本次新增核心）

### 5.1 s5b_dimchain —— 尺寸链校验

| 侧 | 校验内容 | 算法 |
|---|---|---|
| 原图侧 | 线性链闭合：Σ各段 = 封闭环 | 并查集按"接地端点重合"构链 |
| 原图侧 | 径向链闭合：首末半径 + 相邻圆心距 = 外缘总跨度 | 全部换算 mm，每圆心簇取最外圈 |
| 原图侧 | 孔间距 vs 接地坐标反查 | `pitch_vs_dim`，报 error 并带 `text` 定位 |
| 模型侧 | 数值分组闭合：按 (view, axis) 分组，Σ段值 vs 视图跨度 | `check_value_groups`，装不进报 error / 有未标注凸出报 warn |

**实测**（法兰图）：1 条线性链闭合（x 向 552.11 = 75.2+201.3+200.4+75.2）+ 4 条径向链 + 2 warn；模型侧抓出 Front y 向 Σ=120 > 跨度 100 的真实矛盾。

### 5.2 s6b_projection —— 绘图投影原则校验

| 原则 | 判据 | 法兰图实测 |
|---|---|---|
| 长对正 | 主视图 x 范围 = 俯视图 x 范围 | ✅ ok（550.000） |
| 高平齐 | 主视图 z 范围 = 侧视图 z 范围 | ⚠️ 缺侧视图，无从校验 |
| 宽相等 | 俯视图 y 范围 = 侧视图 y 范围 | ⚠️ 缺侧视图 |
| 视图齐全 | 主 + 俯 + 侧三视缺一不可 | ❌ error（缺 Left/Right） |
| 中心共线 | 各视图中心坐标一致 | ✅ ok |
| 图尺相符 | 三视图比例尺一致 | ✅ ok |
| 主视高度链闭合 | Σ高度段 = 主视图总高 | ❌ error（Σ=120 ≠ 100） |

### 5.3 三路校验责任分级（s7_decide 判定顺序）

```
s6b_projection error ─► 图纸投影违规  ─► manual + 禁自动改（图画错了，不一定是模型错）
      ↓ 无
s5b_dimchain error ──► 尺寸链不闭合  ─► manual + 禁自动改（需人工核对是图纸错标还是参数错）
      ↓ 无
s6_compare geom 有差 ─► 三维画错    ─► fix（改 params.py，标注偏差随之消失）
      ↓ 无
s6_compare mark 有差 ─► 二维标注错  ─► manual（查标注层边引用）
      ↓ 无
全部相符 ────────────────────────────► pass
```

**为什么要分级**：图纸本身出错时若自动改参数，是"改错对象"——图错了该修图，参数对了不该动。`suppress_autofix` 标志即为此设。

**实测闭环结论**：法兰图 → `verdict=manual`，诊断语"图纸投影关系违规（2 项：view_missing；height_chain）—— 图画错了，不一定是模型错"，正确跳过参数级建议。

## 6. 输入层：图纸解析（tools/dwg_parser）

Drawing-Recode 思路复现——**不让模型"猜"语义，从像素里分层提取**：

| 层 | 提取内容 | 方法 |
|---|---|---|
| 几何层 | 轮廓边、圆（圆心/半径） | 连通域面积过滤去噪（≥12px，不伤 1px 细线）+ 圆拟合 |
| 标注层 | 尺寸数字、尺寸线、箭头 | 字形几何分类识别 Φ/R（**不用 OCR**）；尺寸界线法区分窄尖刺（2~8px，尺寸界线）与宽鼓包（≥10px，实体边） |
| 接地层 | 接地符号（粗短横线）↔ 数值关联 | 三级判据；残留误差不猜，交给尺寸链校验处理 |

**标定**：法兰图 3.3333 mm/px 先验已知；未知图用标注值反解。

**实测成绩**：6 圆全对、12 条标注全检出、11/12 接地成功、mm/px=0.34012（与理论值吻合）。

**已知局限**（记录在架构文档附录 A）：只在法兰图风上验证过；TechDraw 渲染风（bracket 图）退化明显——14 标注检出 8、Φ 误读、标定偏差 40%。改进方向已写明：标定加箭头对投票、文字—线关联加强约束。

**本次修复的 5 个 bug**（均有回归验证）：

1. **模型侧假端点误报**：`_dims_from_drawing` 自造 `p1=[0,0]` 假端点，12 个尺寸被并成一条链，Σ1895≠550 误报 → 改按 (view, axis) 数值分组闭合
2. **out.data 键名冲突（致命）**：`in_data_from` 平铺合并时 s6b 的 `issues` 字段结构不同互相覆盖，s7 必 KeyError → 两个检验步产出命名空间化（`dimchain`/`projection`），s7 显式按键消费
3. **变量遮蔽**：`run_loop` 里 `for it in issues` 覆盖轮次变量，s9_record 收到 dict 崩溃 → 改名 `x`
4. **medianBlur 吃掉 1px 尺寸线**：300dpi 渲染的尺寸线仅 1px 宽，中值滤波后墨像素 859→77 → 改连通域面积过滤，法兰图重跑结果零变化
5. **缺步骤零件预检失效（本次验证新发现）**：`script_of` 只在某步真正执行时才校验，但 `s0b_dwgread` 是 SHARED 回落步骤且排在链首 → 新零件先跑到它写 `notes/dwg_semantics.json` 时因缺目录崩 `FileNotFoundError`，精心设计的"缺 s1 立刻报错"根本来不及触发（违背 README 承诺）→ 新增 `Driver._check_owned_steps()` **启动即静态预检** s1~s8 是否齐全，缺失一次性列出全部并给出补齐指引

### 8.1 已知容差行为（非 bug，需知晓）

尺寸链闭合校验的容差为 `max(min_tol_mm=0.5, tol_ratio × Σ各段)`，默认 `tol_ratio=0.02`。对跨度 550mm 的链，容差达 **11mm** —— 总长偏差 10mm 会被容差吸收而不报 error。这是**刻意的相对容差设计**（大尺寸零件允许更大的绝对偏差，避免因标定误差误报）。需要更严的判定时收紧 `tol_ratio`（实测 0.005 时 10mm 偏差正确报出）。

## 10. 一页总结

这套系统的骨架是**消息隔离流水线**（mpipe/1 + guard.py），血肉是**单一数据源全链重算**（params.py → 一切产物），灵魂是**闭环自校的责任分级**（投影原则 > 尺寸链 > 模型精度 > 标注精度，图纸出错时坚决不自动改参数）。本次 v2.0 补上了最后两块：前面插了**图纸解析输入层**（s0b + dwg_parser），闭环里插了**两个图纸检验隔离步骤**（s5b 尺寸链 / s6b 投影原则），流水线从 10 步扩到 13 步，全部经过 guard 隔离检查与端到端实测。
