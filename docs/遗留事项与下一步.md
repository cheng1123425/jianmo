## 一、gasket（垫片）：两套独立的出图实现

### 1.1 现状：gasket 与另外三个零件不是同一套代码

| | gasket（垫片，老实现） | bracket / lbracket / ybracket（新实现） |
|---|---|---|
| 文件规模 | `s2_drawing.py` 397 行、`s3_render.py` 165 行 | `s2_drawing.py` 250~283 行、`s3_render.py` 208~254 行 |
| 视图 | **4 个**（多一个轴测图 Iso） | 3 个（Top / Front / Right） |
| 比例 | 0.25 / 0.16 / 0.20（缩小） | 2.0（bracket、lbracket）/ 0.8（ybracket） |
| **标注定位** | **按坐标找边 → `References2D` 绑边** | 按半径找圆 / **两点距离 `makeDistanceDim`** |
| 标注函数 | `dia(view, r, cx, cy, …)`、`disty(view, z1, z2, …)`、`rad_neck(...)` | `add_dia(view, r, …)`、`add_disty(view, y1, y2, …)` |
| 垫片专属逻辑 | 凸台顶线 `boss_top_y`、凹颈 `rad_neck`、侧孔轴线 `side_hole_axis_x` | 无 |

**代码证据**

```python
# gasket —— 按 z 值找两条水平边，绑到边上
def disty(view, z1, z2, X, Y, label):
    k1 = find_hline(view, z1)
    k2 = find_hline(view, z2)
    d.Type = "DistanceY"
    d.References2D = [(view, "Edge%d" % k1), (view, "Edge%d" % k2)]

# 另三个 —— 直接算两点距离，不绑边
def add_disty(view, y1, y2, X, Y, label):
    v1 = App.Vector(0, _y(y1), 0); v2 = App.Vector(0, _y(y2), 0)
    d = TechDraw.makeDistanceDim(view, "DistanceY", v1, v2)
```

### 1.2 为什么本轮没纳入 lib

1. **接口套不上**：`lib/drawing_fc.py` 的 `DrawingBuilder.add_disty` 是两点距离，
   gasket 要的是"按 z 找边再绑 `References2D`"。硬套等于给 gasket 重写一套标注逻辑。
2. **它是默认零件**：`pipe.py` 不带 `--part` 就跑它，改坏的影响面最大。
3. 它现在**工作正常**：闭环 pass、视图不出框。收益 < 风险。

### 1.3 ⚠️ 但要注意：gasket 的做法其实更接近项目目标

`README.md` 里写的是：

> 图纸上的每个尺寸都是 FreeCAD 的 `DrawViewDimension`，用 `References2D` 引用投影边。
> 改三维 → `recompute` → 尺寸值自动跟随。

**只有 gasket 完整做到了这点**。另三个里仅 `add_dia` / `add_rad` 绑边，
`add_distx` / `add_disty` 用的是两点距离。

⇒ **将来若要统一，应该以 gasket 的「绑边」方式为基准去改造另外三个，而不是反过来。**

### 1.4 建议的推进方式（未做）

1. 给 `DrawingBuilder` 增加 gasket 那套方法（`dia_by_center` / `disty_by_edge` / `rad_by_center`），
   让两种标注方式在 lib 里并存（不改动 gasket 现有文件）
2. 逐个零件迁移到绑边方式，每迁一个做一次像素对比验证
3. 最后删掉两点距离那套
