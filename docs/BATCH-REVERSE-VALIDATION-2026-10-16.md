## 2. 根因归类（可迁移到其它 11 件）

**R-A｜把「投影的包络」当成「本体形状」**（外罩 P2）
2D 投影里斜线可能是筋/凸台的投影，尤其在**非 0°/90° 方位**时会被 ×cosθ 压缩。
→ 单靠一张正视图无法区分"本体是锥"还是"筋是斜的"。

**R-B｜把「含圆角的轮廓线」当成「实体尺寸」**（外罩 P3）
细实线/圆角切线在 2D 里和轮廓同色，量出来的永远是**轮廓**而不是**特征尺寸**。
→ 俯视图上的筋、键、法兰台阶都极易踩。

**R-C｜标注未落位就"猜参数"**（外罩 P4/P5）
`notes/plan_src.md` 里挂着 6 条"未定位标注"，最后用 `assumed` 顶上 → 必然错。
→ 标注落位是**硬前置**，落不了位就该报"缺图/缺视图"而不是猜。

**R-D｜自环校验（自己画图自己比对）**（外罩 P1/P2 能"pass"的原因）
`parts/waizhao/drawing.pdf` 是流水线**自己出图**的产物，拿它和模型比对 = 自己跟自己比，
永远 pass。**真值 STEP 是本批唯一的外部锚点。**

**R-E｜标定只有"粗拟合"，没有"细拟合"**（外罩 P6）
`tools/pdf_vector._fit_scale` 在 ±2% 容差下数命中条数，命中一样多时取最小的 k。
→ 系统性偏小 0.4%，而 0.4% 在 Ø48 上就是 0.2mm，在"是否算过公差"上是致命的。

**R-F｜没有"三视图交叉一致性"检查**
外罩的"本体锥 vs 圆柱"只要把**正视图轮廓**与**剖视图 θ=0° 的轮廓**放在一起就立刻露馅，
但流程里没有这一步。

## 3. 建议（流程 / 算子）

> 用户要求"先记录，挨个跑"，以下为**待批**清单。

### S1 ★ 真值定姿算子 `align_truth(step, part)`（新增，P0）
读真值 STEP，自动判定**回转轴 / 主方向**（用 `BRepAdaptor_Surface` 统计 CYL/CONE/SPH 的轴方向 +
包围盒），把真值旋到与重建件同一坐标系（法兰底=z0、轴=Z）。
**这是本批所有对账的前置**（12 件的 STEP 姿态各不相同）。

### S2 ★ 逐面特征清单算子 `face_census(step)`（新增，P0）
输出每个面的 `{类型, 半径, 锥半角, 轴, 位置, 面积}`，直接得到**真值参数表**：
`CYL R=24.000` → 法兰 Ø48；`CYL R=14.000` → 本体 Ø28；`CONE Rref=10.267 半角20°` → 顶帽；
`SPH R=7.000 loc y=-0.99` → 内腔球冠。
**比量像素快一个数量级、且精确到 1e-3**。已实现，见 `dwgwork/gt_vs_mine.py` 的取面部分。

### S3 ★ 体素一致率 + 差异热点（新增，P0）
`ray_profile`（逐 z 扫 r）+ `voxel_diff`（1mm 网格内外判定 → 按 (r,z) 分档出热点）。
外罩用它一眼定位了 P2/P3。建议**定为验收指标**：`体素一致率 ≥ 99%`、`体积差 ≤ 1%`。

### S4 标定最小二乘细化（改 `tools/pdf_vector._fit_scale`，P0）
在现有"命中条数"选出 k 之后，对命中对做 **k 的最小二乘**（`Σ(L_i·k − v_i)²` 最小），
并对 `v_i` 做**整数/半整数偏好**（标注多为 0.5 的整数倍）二次校正。
预期把 mm/pt 从 0.48331 修到 0.48527，一次性消灭 P6 类误差。

### S5 三视图交叉一致性检查（新增，P1）
同一高度 z 上：
`正视图轮廓 == max_θ(剖视图轮廓)`、`俯视图外圆 == 法兰外径`、`剖视图 θ=0 与 θ=90 轮廓 == 本体轮廓`。
不一致即报"疑似把投影包络当本体"，阻止 R-A 类错误。

### S6 标注落位闸门（改 `s0_plan`，P1）
把 `notes/plan_src.md` 的"待确认标注"变成**阻断项**：仍有 ≥1 条未落位的直径/标高标注时，
不允许进入 `s1_build`，直接报"需补视图或需人工确认"。消灭 R-C。

### S7 2D 轮廓 vs 特征尺寸分离（新增，P1）
量尺寸时优先用**图层语义**：`粗实线层`=轮廓、`细实线层`=圆角切线/过渡线。
把"含圆角的轮廓宽度"和"特征宽度"分开报。消灭 R-B。

### S8 验收锚点改用真值（改 `s6_compare`，P1）
`ref_spec.py` 的期望值不再来自"PDF 实测"，而优先来自**真值 STEP 的 face census**（S2）；
PDF 只用来做"标注是否被满足"的二次校验。

### S9 DWG→DXF→三维 的独立支路（新增，P1）
本批 11/12 件都有 DWG。DWG 里 `DIMENSION` 有 `defpoint2/3`（真实测量点），
定位标注**比 PDF 强一档**；应把 `dxf_reader` 正式化为一条与 PDF 并行的重建源。

### S10 迭代收敛环（新增，P2）
`s1_build → 对照真值 → 生成"差异热点报告" → 自动改参 → 重建`，最多 3 轮，
收敛判据用 S3 的体素一致率。外罩人工走的正是这个环（v1→v4），可以自动化。
