## 9. 附：跑闭环时发现的 3 个既有缺陷（**与本次改名无关**）

> ⚠️ **9.1 的结论已在 §10.4 更正**：不是"代码没实现"，而是"实现只在 root 版、
> 零件版是过时副本"—— 又一处"修复不传播"。

第 1 刀改完后跑端到端闭环（三个零件全 pass），过程中暴露 3 个**既有**缺陷。
相关文件 mtime 均早于本会话：`s5b_dimchain.py` 20:08:30、`s6b_projection.py` 20:08:30、
`s7_decide.py` 21:28:19、根 `params.py` 20:03:19 —— **本次改名一个字节都没碰它们**。

### 9.1 `s7_decide` 不消费 s5b / s6b 的结论（**最严重**）

`parts/bracket/steps/s7_decide.py` 的判定只读：

```python
iss    = D.get("issues", [])      # ← 只来自 s6_compare
n_geom = D.get("n_geom", 0)
n_mark = D.get("n_mark", 0)
```

`pipe.py` 明明把三路数据都投给了它（`in_data_from=["s6_compare","s5b_dimchain","s6b_projection"]`），
但 `dimchain` / `projection` 两个命名空间**一行都没读**。

**后果**：v3 文档 §5.3 承诺的责任分级 —— "s6b 投影违规 → manual、s5b 尺寸链 error → manual，
禁止自动改参数" —— **代码里根本没实现**。图纸画错时 `--auto` 仍会照改参数，
正是文档里说要避免的"改错对象"。

**实证**：bracket 本轮 s6b 报了 2 个 error，`s7_decide` 依旧判 `pass`。

### 9.2 `s6b_projection` 浮点比较缺陷

```
! [error] 高平齐不符：主视图高 37.000 ≠ Right 高 37.000（差 -0.000）
```

两个相等的值被判为不等 —— 比较缺容差，应改成 `abs(a - b) > TOL`。

### 9.3 `s5b_dimchain` 疑似读错 `_drawing.json`

三个零件的 s5b 输出**完全相同**：

```
! [warn] 模型侧 Right 视图 y 向尺寸链未覆盖全跨度：ΣH_step = 20.000 < 跨度 100.000
! [warn] 模型侧 Top 视图 x 向尺寸链未覆盖全跨度：Σhole_pitch = 200.000 < 跨度 550.000
```

而 `hole_pitch` / `H_step` 这两个 label **只存在于根目录 `dims_spec.py`（垫片）**，
550 / 100 也正是垫片的主视尺寸 → s5b 读到的是**垫片**的 `_drawing.json`。

疑与 `HANDOFF-2026-10-14.md` §2 修过的 s6b 读错文件 bug **同源**：
`s5b_dimchain.py:147` 的 `_load_json_opt(in_msg, "drawing_json", "drawing_json_file")`
没跟着改成走 `msgio.ref_path()` → 又一次"修复不传播"。

> 这三项都**不影响第 1 刀的结论**（几何一致 + 闭环 pass 成立），
> 但会影响后续把 `s5b`/`s6b` 提升为共享步骤 —— **建议在动第 2 刀之前先修 9.1**，
> 否则"共享"会把一个未实现的分级逻辑固化进框架层。

### 11.1 改了两处

| # | 位置 | 原来 | 改成 | 理由 |
|---|---|---|---|---|
| 1 | `check(dw, tol=…)` | `1e-6` | **`1e-3`** | FreeCAD 投影的数值噪声在 **1e-4 mm 量级**（几何运算累积误差）。1e-6 会把 `37.000 vs 37.000`（实际差 ~4e-5）判成不等，报错还显示「差 −0.000」，自相矛盾。1e-3 远小于任何可制造公差（真错至少差 0.1 mm 量级），足以吸收噪声又不丧失判别力 |
| 2 | 高度链检查条件 | `if hs and "Front" in ext` | **`if len(hs) >= 2 and …`** | 「链」至少要有 2 段；只有 1 条高度标注时谈不上"闭合"。bracket 主视图只标了底板厚 8（总高 37）→ 恒判不闭合，属误报。而且**高度标注分散在侧视图是正常制图习惯**，不该因此报错 |
